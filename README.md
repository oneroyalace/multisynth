# multisynth

Multisynth is a python package that implements classic (Abadie and Gardeazabal 2003) and penalized synthetic control methods (Abadie and L'Hour 2021) for both single and staggered treatment contexts (Wiltshire 2023). 

# Installation

```
git clone https://github.com/oneroyalace/multisynth.git
cd {multisynth_directory}
pip install -e .
```

# Instructions
[examples.ipynb](https://github.com/oneroyalace/multisynth/blob/main/examples.ipynb) shows how to use this package to re-estimate weights from Abadie and L'hour (2021) and Wiltshire (2023)

All methods in my [code](https://github.com/oneroyalace/multisynth/blob/main/multisynth/multisynth.py) are commented. More documentation to come!
